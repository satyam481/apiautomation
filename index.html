Adding a monitor to this collection can give you confidence that the service is up and running and alert you to any breaking changes that may have occurred. ## 🔍 What we’re testing - A very common workflow is the transfer of funds between accounts. We have two scenarios: one which creates all resources and successfully transfers funds, and one which tries the transfer with insufficient funds. - During these workflows, we are testing for data correctness, data types, and that data is successfully passed through the system during creation and retrieval. ## 🔒A note on authorization This API uses an API key-based authorization.
