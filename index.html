If you’re using this collection as a pre-merge check, ensure that all tests are passing before submitting (and no, deleting the failing test cases isn’t an option 😉). Adding a monitor to this collection can give you confidence that the service is up and running and alert you to any breaking changes that may have occurred. ## 🔍 What we’re testing - A very common workflow is the transfer of funds between accounts.
